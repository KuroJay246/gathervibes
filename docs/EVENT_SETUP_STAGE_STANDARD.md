# Event Setup Stage Standard

## Purpose

Event setup stages describe the organizer's progress through the existing event record. They are not a separate workflow, route, collection, or permission model.

## Stages

1. Event Profile: name, type, date, time, venue, and location are defined.
2. Guests & Tickets: capacity, pricing, registration window, and entry rules are ready for guest work.
3. Money Plan: projected registration income or budget categories have been reviewed.
4. Operations Plan: venue access, emergency contact, or event-day timeline is recorded.
5. Ready to Run: readiness checks and open planning work are visible before event day.

## Rules

- A completed event is still editable by approved organizers.
- CPB uses the same standard safeguards as every real event.
- CODEX_TEST is the only special QA/test event and should remain available for synthetic testing.
- Stage labels must not imply that money, attendance, or ticket records were changed automatically.
