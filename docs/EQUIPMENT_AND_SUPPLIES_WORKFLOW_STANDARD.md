# Equipment and Supplies Workflow Standard

## Purpose

Resources tracks the physical and operational items needed to run an event. It covers equipment, supplies, signage, furniture, decor, food/beverage support items, technology, safety items, documents/print, packaging, transport, and other practical event resources.

## Workflow

1. Add the resource under the selected Working Event.
2. Record the quantity needed and quantity confirmed.
3. Mark source type, supplier/contact context, and event location.
4. Use packing, pickup, and return flags only when they are relevant.
5. Link related documents, tasks, Operations entries, commitments, or Run of Show items by ID when useful.
6. Create a follow-up task if organizer action is needed.

## Boundaries

- Resources does not replace Operations Ledger.
- Resources does not calculate registration revenue.
- Supplier/contact links do not grant application access.
- Completed events use the same editable, validated, audited workflow as every other real event.

## Deferred

- Barcode inventory.
- Supplier portal.
- Purchase-order generation.
- Automatic ledger entries.
- Exportable packing lists.
