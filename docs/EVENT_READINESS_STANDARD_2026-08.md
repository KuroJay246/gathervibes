# Event Readiness Standard - 2026-08

## Purpose

Overview should summarize whether the selected Working Event is ready for organizer action. Readiness signals must remain compact and must not duplicate full route workspaces.

## Current Readiness Inputs

- Event setup and venue details.
- Registrations, guest counts, payment follow-up, missing tickets, missing contacts, duplicate contact warnings, and finance review rows.
- Operations entries, event-level income/expense/commitment state, and partner records.
- Tasks and deadlines.
- Run of Show item count and delayed timeline items.
- Resource count and shortage state.

## Boundaries

- Registration payments and Operations remain separate.
- Run of Show does not automatically create tasks.
- Resources do not automatically create Operations Ledger entries.
- CODEX_TEST remains the only QA/test classification.
- Real completed events remain editable through normal safeguards.

## Deferred

- Weighted readiness scoring by event category.
- Exportable readiness report.
- Organizer-configurable readiness thresholds.
