# Response Inbox Review Standard

## Purpose

Response Inbox is the intake queue before Import Center. It helps the organizer decide whether a form response is new, needs review, is waiting for information, looks duplicated, or can continue to Import Preview.

## Review States

- New
- Needs Review
- Approved
- Ready to Import
- Imported
- Waiting for Information
- Wait-Listed
- Duplicates
- Rejected
- History

## Actions

Available actions are Review, Approve, Request Information, Wait-List, Reject, Mark Duplicate, and Link Existing. These actions update review state only. They do not create a registration.

## Request Information

Request Information does not send a message. It can move the response to Waiting for Information and open Message Builder so the organizer can copy prepared text into another tool.
