# Organizer Action Hierarchy Standard

## Primary Actions

Primary actions should create or update the page's core record type and must remain visually stronger than navigation shortcuts.

## Secondary Actions

Secondary actions may link to adjacent workflows, filter data, copy content, or open review surfaces. They should not compete with the primary action.

## Destructive Actions

Destructive actions require confirmation and append-only audit coverage where supported. They must not be visually equivalent to routine status buttons.

## Mobile Priority

The mobile primary navigation remains:

- Overview
- Guests
- Tickets
- Check-In
- More

System QA remains available under More and is not treated as an event-day primary action.
