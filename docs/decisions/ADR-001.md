# ADR-001: React and Vite frontend

Status: Accepted
Date: 2026-08-21
Superseded by: None

## Context

Gathetr is a browser-delivered event operations SPA with many organizer routes and local/emulator testing needs.

## Decision

Use React 19, React Router, Vite, and Firebase client SDK as the frontend architecture.

## Alternatives

- Keep the behavior undocumented: rejected because this app has production data and complex Firestore authorization.
- Replace the system during documentation: rejected because Phase 3 is documentation-only.

## Consequences

Fast local development, static Firebase Hosting deployment, route-level lazy loading, and browser-based QA.

## Affected Systems

Gathetr source code, tests, Firebase configuration, Firestore Rules, and owner/developer documentation.

package.json; src/App.jsx; vite.config.js
