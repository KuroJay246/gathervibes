# ADR-005: Preview-first import architecture

Status: Accepted
Date: 2026-08-21
Superseded by: None

## Context

Imports can create many records and must avoid accidental writes.

## Decision

Parse and preview CSV/XLSX/pasted rows before explicit final confirmation and chunked writes.

## Alternatives

- Keep the behavior undocumented: rejected because this app has production data and complex Firestore authorization.
- Replace the system during documentation: rejected because Phase 3 is documentation-only.

## Consequences

Safer import workflow; more validation code; easier troubleshooting.

## Affected Systems

Gathetr source code, tests, Firebase configuration, Firestore Rules, and owner/developer documentation.
