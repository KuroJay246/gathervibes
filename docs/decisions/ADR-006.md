# ADR-006: Documentation as source plus generated PDF

Status: Accepted
Date: 2026-08-21
Superseded by: None

## Context

Future maintainers need searchable offline documentation without relying on chat history.

## Decision

Keep Markdown source in docs and generate a PDF snapshot.

## Alternatives

- Keep the behavior undocumented: rejected because this app has production data and complex Firestore authorization.
- Replace the system during documentation: rejected because Phase 3 is documentation-only.

## Consequences

Docs can be reviewed in Git and shared as PDF; generated artifacts must be rebuilt after meaningful changes.

## Affected Systems

Gathetr source code, tests, Firebase configuration, Firestore Rules, and owner/developer documentation.
