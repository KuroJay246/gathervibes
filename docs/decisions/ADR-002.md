# ADR-002: Firebase backend and Firestore Rules

Status: Accepted
Date: 2026-08-21
Superseded by: None

## Context

The app needs private authenticated data, event-scoped reads/writes, and append-only audit evidence.

## Decision

Use Firebase Auth, Cloud Firestore, Firestore Rules, and Firebase Hosting.

## Alternatives

- Keep the behavior undocumented: rejected because this app has production data and complex Firestore authorization.
- Replace the system during documentation: rejected because Phase 3 is documentation-only.

## Consequences

Security must be kept in Rules and tested with emulators before production deploys.

## Affected Systems

Gathetr source code, tests, Firebase configuration, Firestore Rules, and owner/developer documentation.

## References

src/lib/firebase.js; firestore.rules; firebase.json
