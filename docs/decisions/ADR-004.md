# ADR-004: Privacy-safe QR ticket payload

Status: Accepted
Date: 2026-08-21
Superseded by: None

## Context

Tickets need QR scanning without embedding private guest information.

## Decision

QR payload is GSV:TICKET:{ticketCode}.

## Alternatives

- Keep the behavior undocumented: rejected because this app has production data and complex Firestore authorization.
- Replace the system during documentation: rejected because Phase 3 is documentation-only.

## Consequences

Stable lookup format; no private data in QR; migration required for any future payload change.

## Affected Systems

Gathetr source code, tests, Firebase configuration, Firestore Rules, and owner/developer documentation.
