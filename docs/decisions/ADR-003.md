# ADR-003: Protected Owner and approved organizer model

Status: Accepted
Date: 2026-08-21
Superseded by: None

## Context

Settings access must not be able to lock out the owner while approved organizers remain manageable.

## Decision

Protected Owner access is UID-based; organizer access is sourced from settings/accessControl.

## Alternatives

- Keep the behavior undocumented: rejected because this app has production data and complex Firestore authorization.
- Replace the system during documentation: rejected because Phase 3 is documentation-only.

## Consequences

Owner remains recoverable; Settings must display the same authoritative source used by auth.

## Affected Systems

Gathetr source code, tests, Firebase configuration, Firestore Rules, and owner/developer documentation.
