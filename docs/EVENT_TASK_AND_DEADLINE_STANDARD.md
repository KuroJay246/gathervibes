# Event Task and Deadline Standard

## Purpose

Event tasks record organizer work needed to prepare, run, or close out an event. They live on the existing event document as `planningTasks`.

## Deadline Labels

- Overdue: open task due before today.
- Due today: open task due today.
- Due soon: open task due within the next 7 days.
- Open: task has no urgent due date or no due date.
- Completed: task is done and excluded from urgent deadline counts.

## Product Rules

- Tasks must remain event-scoped.
- Tasks must not alter registration finance totals.
- Tasks must not alter Operations ledger totals.
- Tasks must not alter tickets or check-ins.
- CODEX_DEMO may be used for QA task checks.
- CPB must use the same task safeguards as every other real event.

## Organizer Wording

Use plain labels such as "Task deadline focus", "Open tasks", "Overdue", "Due today", and "Due soon". Do not use implementation-phase language in organizer UI.
