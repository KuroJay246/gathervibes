# Import Template And Header Mapping Standard

## Templates

Templates provide safe headers and examples for common organizer sources. They are not integrations and do not bypass preview or confirmation.

## Header Mapping

Header review should show:

- Original imported header.
- Detected Gather & Savor field.
- Confidence.
- Example value from the uploaded or pasted rows.
- Mapping status.
- Duplicate or conflicting header warnings.

Extra columns may be ignored. If an extra column contains useful operational context, the organizer may preserve it in Notes when that does not expose credentials, private links, bank/card details, or unrelated personal data.

## Write Boundary

Mapping does not write records. Validation and duplicate review must occur before the final import confirmation.
