# Organizer Page Explanation Standard

## Required Explanation

Each route should be understandable without release notes. The organizer should see:

- what the page helps them do;
- what event the page is scoped to;
- what the page will not change automatically;
- where to go next if they need a connected workflow.

## Current Page Purposes

- Overview summarizes current event status and next actions.
- Events manages event setup and Working Event selection.
- Tasks & Deadlines tracks event-scoped work.
- Guests & Registrations manages guest records and registration payment fields.
- Registration Payments reviews payment evidence and balances.
- Tickets prepares QR access using `GSV:TICKET:{ticketCode}`.
- Check-In tracks event-day attendance.
- Operations tracks event-level money and obligations.
- Run of Show manages event-day timing and dependencies.
- Resources manages supplies and equipment readiness.
- Documents records references and evidence links.
- Contacts & Partners manages reusable people, businesses, and event relationships.
- Message Builder creates copyable messages only.
- Reports provides read-only event review.
- Import Center uses preview-first data intake.
- Settings contains practical defaults.
- System QA contains diagnostics and safe CODEX_DEMO guidance.
