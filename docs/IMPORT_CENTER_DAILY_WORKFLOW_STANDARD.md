# Import Center Daily Workflow Standard

## Standard Flow

1. Choose the source.
2. Choose the record type.
3. Upload or paste rows.
4. Review template guidance.
5. Confirm headers.
6. Map required fields.
7. Review validation groups.
8. Resolve or exclude problem rows.
9. Confirm the Working Event and write behavior.
10. Review the result and retry remaining rows where supported.

## Supported Write

Guest Registration is the only record type that writes through Import Center. All other record types remain review-only until a real destination workflow exists.

## Guardrails

Import Center does not connect Gmail, live Google Sheets, OCR, AI, or third-party parsing. It does not bypass preview, validation, duplicate review, or final confirmation.
