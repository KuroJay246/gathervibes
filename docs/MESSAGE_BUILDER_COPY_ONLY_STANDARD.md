# Message Builder Copy-Only Standard

## Product Boundary

Message Builder prepares operational text from structured event data. It is not a sending platform, campaign tool, CRM, or AI writer.

## Required Wording

`Message Builder prepares text only. It does not send email or WhatsApp messages.`

## Allowed Actions

- Copy Message
- Copy Subject
- Copy Both
- Copy recipient list
- Copy CSV packet
- Copy deterministic prompt text for an external drafting tool

## Disallowed Claims

The UI must not claim Sent, Delivered, Email sent, WhatsApp sent, live Gmail connection, live WhatsApp connection, or real AI generation unless a future approved integration implements that capability.
