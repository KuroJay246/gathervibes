# Event Report and Reconciliation Standard

## Reports
- Lead with the selected event summary and administrative review.
- Keep Registration Payments, Operations, commitments, in-kind support, planned figures, and attendance as separate concepts.
- State clearly that Reports is read-only.
- Do not imply that event completion makes the event immutable.

## Reconciliation
- State clearly that reconciliation status is not the same as payment status.
- Show payment balance and evidence discrepancy as separate review concepts.
- Keep reconciliation scoped to the selected Working Event only.
- Keep the page preview-only unless a separately approved audited apply workflow exists.

## Guardrails
- Do not merge Registration Payments and Operations into one ledger.
- Do not calculate final profit from this surface.
- Do not write payment corrections from the reconciliation preview.
- Keep test-event boundaries and event scope intact.
