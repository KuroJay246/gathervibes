# Import and Response Intake Refinement Result - 2026-08

## Result

Import Center and Response Inbox now read as one intake workflow. Source choices use concise format/status language, record types distinguish supported writes from review-only records, the workflow stepper exposes current/completed/upcoming state to assistive technology, and final confirmation summarizes the event, source, row counts, destination, and write behavior.

## Response Inbox

- Connection status uses truthful labels such as Manual Response Review.
- Filters now match organizer review states: New, Needs Review, Approved, Ready to Import, Imported, Waiting for Information, Wait-Listed, Duplicates, Rejected, and History.
- Response cards show Source, Respondent, Submitted Information, Mapping, Review Status, Duplicate Information, and Next Action.
- Request Information marks review status only and links to Message Builder for copyable follow-up text.

## Safety

Approving a response does not import it. Continuing approved responses to mapping still requires normal validation, preview, and explicit confirmation.
