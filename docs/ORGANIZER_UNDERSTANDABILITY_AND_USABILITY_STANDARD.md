# Organizer Understandability and Usability Standard

An organizer-facing feature is not complete merely because it technically works.

Every changed organizer surface must make these points clear within 5-10 seconds:

- What page this is.
- What belongs here.
- Which Working Event is selected.
- What needs attention.
- What the primary action is.
- Which statuses are manual versus automatic.
- what the page does not change automatically.
- What linked records do and do not change.
- Which actions are destructive.
- What to do next.

Forms should use plain sections: Basic information, Date and time, Responsibility, Related information, Status and follow-up, Notes, and Advanced options.

Error messages must distinguish authorization, validation, older-record compatibility, wrong Working Event, network failure, missing required fields, stale data, and audit-write failure.

Mobile review must confirm readable text, touch-friendly controls, no horizontal overflow, and no bottom-navigation overlap.

Tutorial and CODEX_DEMO must stay current with visible navigation, terminology, status, and workflow changes.
